# My Portfolio Website

A website to showcase some of my projects!🚀

## Features

- Responsive design
- Interactive UI

## Technology Stack

- Next.js
- Tailwind CSS

## Installation and Setup
Feel free to clone my repo:
```bash
git clone 'https://github.com/sonyerg/portfolio-nextjs-app'
cd [portfolio-nextjs-app]
npm install
npm run dev
```
